# Codex Skills

This repo includes custom Codex skills under codex_skills/.

## Install (Windows)
Run PowerShell:

`powershell
.\install_codex_skills.ps1
`

This copies each skill folder into:
- C:\Users\admin\.codex\skills\<skill-name>\SKILL.md

## Update
Re-run the install script.

## Uninstall
Delete the corresponding folders under C:\Users\admin\.codex\skills.
